# The Women’s Question

A simple static website designed for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository, e.g. `the-womens-question`.
2. Upload `index.html` and `styles.css` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the live Pages URL once deployment finishes.
